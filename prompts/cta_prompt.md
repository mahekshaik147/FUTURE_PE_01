# CTA Prompt

## Objective
Generate persuasive call-to-action website copy for a modern cafe.

---

## Prompt

Act as a conversion-focused website copywriter.

Generate 5 strong CTA sections for "Brew Haven Cafe" in Bangalore.

Requirements:
- Encourage customers to visit the cafe
- Promote table reservations
- Build trust and comfort
- Create a warm and inviting feeling
- Use emotional and sensory language
- Avoid generic AI phrases
- Keep each CTA short, persuasive, and website-ready

Include CTAs for:
1. Visit Today
2. Reserve a Table
3. Work-Friendly Cafe
4. Weekend Hangouts
5. Coffee & Dessert Lovers

Tone:
Friendly, cozy, modern, premium, welcoming.

Output format:
- CTA Heading
- Short Persuasive Text
- CTA Button Text
