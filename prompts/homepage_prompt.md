# Homepage Copy Prompt

## Objective
Generate conversion-focused homepage copy for a local cafe website.

---

## Prompt

Act as an expert website copywriter for local businesses.

Generate homepage website copy for a modern cafe called "Brew Haven Cafe" located in Bangalore.

Target audience:
- Students
- Young professionals
- Coffee lovers
- Remote workers
- Friends looking for a cozy hangout spot

Cafe vibe:
- Warm
- Modern
- Cozy
- Instagram-friendly
- Work-friendly atmosphere

Requirements:
1. Write a strong homepage headline
2. Write a persuasive subheadline
3. Create a short introduction paragraph
4. Add a “Why Choose Us” section
5. Mention:
   - freshly brewed coffee
   - relaxing atmosphere
   - free WiFi
   - handcrafted desserts
6. Add a strong CTA encouraging customers to visit or reserve a table
7. Use natural, human-like language
8. Keep content website-ready

Tone:
Friendly, modern, inviting, premium but simple.

Output format:
- Headline
- Subheadline
- Intro
- Why Choose Us
- CTA
